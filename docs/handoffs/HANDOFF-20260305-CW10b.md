## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| Tier derived from relevancy (no separate toggle) | `>5 = nah`, `<=5 = satellit` — single slider instead of two controls simplifies UI |
| `input` event for live preview, `change` for snapshot | Prevents flooding undo stack while giving immediate visual feedback |
| `::before` pseudo-element for gradient wash | Avoids modifying the node's own background; `pointer-events: none` keeps interactivity |
| `--sector-rgb` as inline CSS variable | Single CSS rule handles all sector colors; no per-color class generation needed |
| 4 of 12 tasks needed zero code changes (tests only) | Architecture already handles meta through JSON.stringify deep clones — tests just verify the guarantee |

## Deviations from PRD

| PRD | Actual | Reason |
|-----|--------|--------|
| Separate `tier` toggle (Nah/Satellit) | Tier derived from relevancy slider | Reduces UI complexity; one control instead of two |
| `meta.tier` as stored enum | `getTier()` function derives at render time | Prevents stale tier values when relevancy changes |
