## Conclusion & Lessons Learned

**Closed:** 2026-03-05 | **Outcome:** completed

### Lessons

1. **[ARCHITECTURE] Event bus eliminates callback threading without adding complexity.** Replacing `fullRenderFn` callback injection across 4 modules with a 15-line `on()`/`off()`/`emit()` bus in state.js removed all module-level function references. The key insight: the bus lives in state.js (already the shared dependency) so no new imports are needed.

2. **[ARCHITECTURE] Unifying duplicate logic catches hidden behavioral divergence.** The two `loadProject` implementations had silently diverged — one used `applyTheme()`, the other set `data-theme` directly; one handled legends, the other didn't. A single source of truth with an `opts` parameter fixed both bugs while reducing code.

3. **[PROCESS] Bottom-up extraction order makes big refactors safe.** Extracting small helpers (A4-A7) first reduced the diff size when the event bus (A3) and sidebar split (A1) landed. Each commit was independently verifiable via `node build.js`.

4. **[CODE-PATTERN] Callback parameters break circular deps better than event re-export.** When settings-panel.js needs `refreshSidebar()` from sidebar.js, passing it as a callback parameter avoids a circular import. Simpler than re-exporting through a third module or using the event bus for UI-internal concerns.

5. **[PROCESS] Subagent-driven development with spec review catches issues early.** Dispatching fresh subagents per task kept context clean across 7 sequential refactoring tasks. The two-stage review (spec compliance + quality) caught the `getNodesBoundingBox` API mismatch before it became a problem.

## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| `domCache` as module-level `Map` in renderer.js | Shared across renderer + interactions + sidebar without global state pollution |
| RAF-gate via flag + rAF wrapper | Simpler than throttle utilities; exactly matches display refresh rate |
| Debounce + beforeunload pattern | 500ms reduces 95% of save overhead; beforeunload prevents data loss edge case |
| Cache CSS vars at init + event listeners | Avoids `getComputedStyle` in hot loops; resize/theme events are rare enough to re-read |
| Diff-based selection rendering | O(changed) instead of O(all); prevSelectedIds Set makes diffing trivial |
| Event bus in state.js (not separate module) | state.js is already the universal dependency — adding bus there requires zero new imports |
| Sidebar split: 3 files via callback params | settings-panel and project-manager never import sidebar → no circular deps |
| Unified loadProject with `opts.resetState` | URL loading (no prior state) passes `false`; sidebar loading passes `true` |
