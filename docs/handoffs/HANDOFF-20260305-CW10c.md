## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| Auto-mapping only (no manual column remapping UI) | 95%+ of imports use our own export format; manual mapping is ~40% effort for <5% of use cases |
| Fuzzy header aliases (German + English) | Handles minor variations (Name→Label, Kontakt→contact) without any UI complexity |
| Unknown columns → `meta.<headerName>` | Preserves custom data from external CSVs without loss |
| Match existing nodes by label (case-insensitive) | Labels are the natural human-readable identifier; avoids exposing internal IDs |
| Don't change type of existing nodes on import | Prevents accidental sector→company type demotion |
| Import dropdown mirrors export dropdown | Consistent UI pattern, scales for future format support |
| Preview modal with counts (new/updated) | Users see impact before committing; builds trust |
