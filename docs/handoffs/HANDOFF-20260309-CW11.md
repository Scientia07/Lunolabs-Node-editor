## Completed This Session

### S1: Prototype Pollution Guard — Security Fix
- Added `safeMetaKey()` to utils.js — rejects `__proto__`, `constructor`, `prototype`, empty strings, keys > 200 chars
- Applied in sidebar.js (3 locations: custom key edit, delete key, add new field)
- Applied in csv-import.js (2 locations: header mapping, meta value assignment)
- 7 new unit tests covering all rejection cases

### P1: Connection Adjacency Index — Performance Fix
- Replaced O(n) full-scan `getNodesConnectedTo()` with O(1) Map-based `_adjMap`
- `rebuildAdjMap()` builds `Map<nodeId, Set<nodeId>>` once from connections array
- Called at entry points: `refreshSidebar()` and `getHiddenNodeIds()`
- Impact: BFS hierarchy + visibility computation drops from O(n × c) to O(n + c)

### P2: Slider Input Debounce — Performance Fix
- node-popup.js: Added `debouncedRender()` using `requestAnimationFrame` — coalesces 60fps input events to max 1 render per frame
- Applied to color pickers (×2), angle slider, opacity slider, font size slider
- sidebar.js: Removed `emit('render')` from relevancy slider `input` handler — updates value display + tier badge locally; full render on `change` (release) only

### Connection Labels — New Feature
- `conn.label` string property on connection objects (auto-persisted, auto-serialized)
- "Beschriftung" text input in conn-popup Stil tab
- SVG rendering: `<rect>` background pill + `<text>` at connection midpoint
- PNG export: `measureText()` for exact width, white background pill with border
- Zero-cost persistence: label is part of `state.connections` array, already serialized

## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| Adjacency map rebuilt at entry points (not on every call) | `refreshSidebar()` and `getHiddenNodeIds()` are the only callers; rebuilding once per cycle is sufficient |
| `requestAnimationFrame` debounce (not setTimeout) | Aligns with browser paint cycle; at most 1 render per frame, zero latency on final value |
| Connection label at geometric midpoint `(from+to)/2` | For this codebase's bezier curves (40% control points), the curve midpoint at t=0.5 equals the geometric midpoint — no special math needed |
| Label stored as `conn.label` (not separate array) | Follows existing pattern (color, dash, width on connection object); auto-serialized, auto-undoable |
| Background pill with estimated width `len * 6.5 + 12` | SVG has no `measureText()`; character-count estimation is good enough at 11px font; PNG export uses exact `ctx.measureText()` |
