## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| Pure functions with data params (not module-level state) | Makes graph-utils.js testable without mocking — 20 tests, zero DOM deps |
| `_adjMap` cache stays in sidebar.js (not graph-utils) | The cache is module-level mutable state — pure module shouldn't hold it |
| `handleToolCreation` receives `editNodeLabel` as callback | Avoids circular dep: node-creation.js → interactions.js → node-creation.js |
| SVG text wrapping via char-width estimation (`avgCharW = 7`) | SVG has no `measureText()` — good enough for 13-14px DM Sans, simpler than hidden DOM measurement |
| 20px padding around SVG viewBox | Prevents edge-clipping of nodes at the bounding box boundary |
| `gradientUnits="userSpaceOnUse"` for SVG gradients | Absolute coordinates match the Canvas API gradient behavior exactly |
