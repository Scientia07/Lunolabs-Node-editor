# Session Handoff — CW10 (2026-03-04)

**Project:** Netzwerk-Editor (Node Editor for Jugendbuero)
**Session Focus:** Sidebar panel with connections list, group visibility toggles, settings, and project management

---

## Completed This Session

### 1. Right-Side Sidebar Panel (new feature)
- **3-tab layout**: Verbindungen, Gruppen, Einstellungen
- Collapsible with toggle button on right edge + keyboard shortcut `P`
- Smooth CSS transitions for open/close, canvas and panels shift accordingly

### 2. Connections Tab
- Lists all connections grouped by source node
- Color dots match connection color
- Click to highlight + pan canvas to connection midpoint
- Hover highlights connection on canvas (thicker stroke + glow)
- Delete button per connection (with undo support)

### 3. Groups Tab
- **Auto groups (Sektoren)**: Each sector/center node auto-creates a group showing connected node count
- **Eye icon toggle**: Hides/shows entire sector cluster (sector + all connected nodes + their connections)
- Smart visibility: nodes connected to multiple sectors stay visible if any parent sector is visible
- **Custom groups**: Create named groups, assign selected nodes, toggle visibility, delete
- **Assign selection**: When nodes are selected and custom groups exist, shows quick-assign buttons

### 4. Settings Tab
- **Project management**: Lists embedded + saved projects, load/save/import/download/new
- **Project name**: Editable input
- **Connection style**: Bezier / Straight dropdown
- **Default connection color**: Color picker with hex display
- **Grid**: Visibility toggle, snap toggle, size slider (10-80px)
- **Theme**: Dark / Light dropdown
- **Info**: Node and connection counts

### 5. Project Management System
- **Embedded projects**: Build embeds all JSON files from `src/data/` into the HTML via `window.__EMBEDDED_PROJECTS__`
- **Saved projects**: localStorage-based persistence — save by name, auto-listed on next open
- **Import**: Load any `.json` file, auto-saves to localStorage
- **Download**: Export current project as `.json` file for sharing/backup
- **Template loading**: Embedded projects shown with VORLAGE badge, click to load

### 6. Build System Updates
- Build now writes to both `dist/index.html` and root `index.html`
- CSS build order includes `sidebar.css`
- All `src/data/*.json` files embedded into HTML at build time
- `project.js` checks `window.__EMBEDDED_PROJECTS__` before `fetch()` — works offline and from `file://`

### 7. Keyboard & Input Fixes
- Added `P` shortcut to toggle sidebar
- Expanded keyboard guard to skip `INPUT`, `SELECT`, `TEXTAREA` elements (was only `contentEditable`)

## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| Visibility via DOM `display:none` not state removal | Undo/redo, save/load, export all still see full graph |
| Groups + hiddenSectors in undo snapshots | Toggling visibility is fully reversible |
| localStorage for user-saved projects | Browser app can't write files; localStorage persists across sessions |
| Embedded projects via `window.__EMBEDDED_PROJECTS__` | Single HTML file works offline and from `file://` protocol |
| Sidebar starts closed | Doesn't change default UX; discovered via toggle or `P` key |
| `padding-top: var(--toolbar-h)` on sidebar | Prevents tab labels from hiding behind the fixed toolbar |
| Build writes to root `index.html` too | User was opening stale root file; prevents confusion |
