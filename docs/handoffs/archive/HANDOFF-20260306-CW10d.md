## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| Sidebar tab (not Spotlight overlay) | Keeps results visible during canvas navigation; users can click through results |
| Lightweight fuzzy (not substring or Levenshtein) | Handles abbreviations ("jgb" → "Jugendbuero") without typo-tolerance overhead |
| No debounce on search input | 131 nodes search completes in <1ms; debounce adds latency for no benefit |
| CSS classes not inline styles for dim/highlight | Composable with selection, satellite wash, hidden sectors |
| `!important` on `.search-dimmed` opacity | Must override per-node relevancy opacity for clear visual distinction |
| Search all meta fields (not just label) | Contact names, tags, notes are common search targets |
