## Conclusion & Lessons Learned

**Closed:** 2026-03-09 | **Outcome:** completed

### Lessons

1. **[ARCHITECTURE] BFS layers solve hierarchy display for graphs with shared children.** Per-node tree collapse is ambiguous when a node connects to multiple parents. Layer-based collapse (all nodes at depth N) sidesteps ownership ambiguity entirely.

2. **[CODE-PATTERN] Lightweight custom events decouple render paths without full re-render.** Adding `editor:selection` as a targeted DOM event let the sidebar react to selection changes without triggering expensive canvas re-renders.

3. **[ARCHITECTURE] UI-only state belongs in module scope, not persisted state.** `collapsedLayers` is transient view preference — storing it as a module-level Set prevents save/undo cycles and keeps serialized state clean.

## Completed This Session

### Phase 11: Hierarchy Scaffold & Sidebar Bugfix (H1-H4)

- **H1**: BFS hierarchy layers — `buildHierarchyLayers()` starts from the most-connected node, each BFS wave = one indentation level. Nodes sorted by connection count within each layer. Disconnected nodes appear at the end.
- **H2**: Collapsible layer headers — `collapsedLayers` Set (module-level, UI-only). Headers show "Hub" / "Ebene N" with node count + chevron. Click toggles.
- **H3**: Scaffold CSS — `.scaffold-layer-header` with hover, chevron rotation animation. Layer 0 gets `font-weight: 600` + larger color dot. Layer 1 gets `font-weight: 500`.
- **H4**: Bugfix — Details tab didn't update when switching nodes. Root cause: `renderSelectionState()` only toggled CSS classes without notifying sidebar. Fix: dispatches `editor:selection` event when selection changes; sidebar listens for it.

## Key Decisions Made

| Decision | Rationale |
|----------|-----------|
| BFS layers (not per-node tree collapse) | Graph nodes can have multiple parents; layer-based avoids ambiguity |
| `collapsedLayers` as module-level Set | UI-only state — no need to persist or trigger undo cycles |
| `editor:selection` custom DOM event | Lightweight; decouples renderer from sidebar; no full re-render |
| Event guard `toAdd.size \|\| toRemove.size` | Prevents spurious refreshes when selection doesn't actually change |
