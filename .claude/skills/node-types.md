# Node Type System — Netzwerk-Editor

## Current Node Types

| Type | CSS Class | Shape | Has Gradient | Has Resize | Special |
|------|-----------|-------|-------------|------------|---------|
| `center` | `node-center` | Circle | Yes | No | Main hub node |
| `sector` | `node-sector` | Circle or rounded rect | Yes | No | `size` field → circle variant |
| `company` | `node-company` | Card or text | No | No | `parentId` → text variant |
| `sticky` | `node-sticky` | Rectangle | No | Yes | Random color, fold corner |
| `rect` | `node-rect` | Rounded rect | No | No | Border color |
| `circle` | `node-circle` | Circle | No | No | Width = Height enforced |
| `textbox` | `node-textbox` | Invisible | No | No | Text only |

## Node Data Shape

All nodes are plain objects with these fields:

```javascript
{
  id: 1,              // Unique integer, generated by genId()
  type: 'sector',     // One of the types above
  x: 200, y: 300,     // Canvas position (top-left corner)
  label: 'My Node',   // Display text (supports \n for multiline)

  // Optional — type-dependent:
  color: '#6c8aff',   // Primary color
  color2: '#ff6b6b',  // Gradient end color
  gradAngle: 135,     // Gradient angle in degrees
  opacity: 0.8,       // 0-1, applied as CSS opacity and canvas globalAlpha
  width: 140,         // Explicit width (sticky, rect, circle)
  height: 80,         // Explicit height (sticky, rect)
  borderColor: '#d0d0dd', // Border color (rect, circle)
  font: "'Inter', sans-serif",
  fontSize: 14,
  fontWeight: 600,

  // Type-specific:
  size: 'lg',         // sector circle variant size
  parentId: 5,        // company text variant — linked to sector
  underlined: true,   // company text variant
}
```

## Adding a New Node Type

### Step 1: Renderer (`src/js/renderer.js`)

Add an `else if` block in `createNodeElement(n)`:

```javascript
} else if (n.type === 'mytype') {
  el.className = 'node node-mytype';
  el.style.background = n.color || 'var(--bg-elevated)';
  if (n.width) el.style.width = n.width + 'px';
  if (n.height) el.style.height = n.height + 'px';
  // Add resize handle if resizable:
  // el.appendChild(Object.assign(document.createElement('div'), { className: 'resize-handle' }));
}
```

The renderer also adds:
- A `<span class="node-label">` with the label text
- Four `.anchor` divs (top, bottom, left, right) for connections
- `.selected` class if the node is in `state.selectedIds`

### Step 2: CSS (`src/styles/nodes.css`)

```css
.node-mytype {
  /* Base dimensions, colors, typography */
  min-width: 100px;
  padding: 12px;
  border-radius: 8px;
  border: 2px solid var(--border);
}
```

### Step 3: PNG Export (`src/js/export-png.js`)

Add a rendering block in the `state.nodes.forEach(n => { ... })` section:

```javascript
} else if (n.type === 'mytype') {
  ctx.fillStyle = n.color || '#f0f0f5';
  ctx.strokeStyle = n.borderColor || '#d0d0dd';
  ctx.lineWidth = 2;
  roundRect(ctx, x, y, w, h, 8);
  ctx.fill();
  ctx.stroke();
  // Label
  ctx.fillStyle = '#1a1a2e';
  ctx.font = `400 13px ${fontFam}`;
  ctx.textAlign = 'center';
  ctx.textBaseline = 'middle';
  ctx.fillText(n.label || '', x + w / 2, y + h / 2);
}
```

**Important:** The export uses canvas 2D API, not DOM. Every visual feature must be manually drawn:
- `roundRect()` for rounded rectangles
- `ctx.arc()` for circles
- `wrapText()` for multi-line text
- `ctx.save()` / `ctx.restore()` wraps each node (handles opacity via `globalAlpha`)

### Step 4: Toolbar (optional)

To add a toolbar button for creating the new type:

1. Add button HTML in `src/index.html` toolbar section
2. Wire in `src/js/toolbar.js` or add to shapes dropdown
3. Handle creation in `interactions.js` `onMouseDown` empty-canvas section:
   ```javascript
   if (state.tool === 'mytype') {
     saveSnapshot();
     const node = { id: genId(), type: 'mytype', x: snapToGrid(cp.x), y: snapToGrid(cp.y), label: '', ... };
     state.nodes.push(node);
     rebuildIndex();
     fullRenderFn();
     setTimeout(() => editNodeLabel(node.id), 100);
     return;
   }
   ```

### Step 5: Node Popup (`src/js/node-popup.js`)

Add the type to the `<select id="np-type">` dropdown in `src/index.html`:
```html
<option value="mytype">My Type</option>
```

Add default dimensions in `applyType()`:
```javascript
if (newType === 'mytype' && !n.width) { n.width = 140; n.height = 80; }
```

### Step 6: Context Menu

No changes needed — the context menu uses the same items for all node types (edit, color, font, duplicate, delete).

## Type Variants

Some types have variants based on data fields:

- **Sector**: `n.size` present → circle variant (`node-sector--circle`), absent → rounded rect
- **Company**: `n.parentId != null` → text variant (`node-company--text`), absent → card with color dot

To add a variant, use the same type but check for a distinguishing field:
```javascript
if (n.type === 'sector') {
  if (n.size) {
    el.className = 'node node-sector node-sector--circle';
  } else {
    el.className = 'node node-sector';
  }
}
```

## Connection Rendering

Connections are drawn in `renderConnections()` as SVG `<path>` (bezier) or `<line>` (straight) elements. They connect node anchor points. Adding a new node type requires NO changes to connection rendering — the anchor system works for all types.

## Rendering Pipeline

```
state.nodes mutated
  → fullRender() called (or editor:render event)
    → renderNodes()         — wipes nodesLayer, creates all node DOM elements
    → renderConnections()   — wipes svgLayer, draws all SVG connections
    → applyVisibility()     — hides nodes in hidden groups/sectors
    → updateMinimap()       — redraws minimap canvas
    → refreshSidebar()      — updates sidebar lists
```

Every call to `renderNodes()` destroys and recreates ALL node DOM elements and rebuilds the `domCache` Map. This means:
- No need to update individual elements — just re-render
- `domCache.get(nodeId)` provides O(1) DOM element lookups (replaces all `querySelector('[data-id="X"]')`)
- But also: any external DOM references (contenteditable, focus) are lost
- That's why `editNodeLabel()` uses `setTimeout(() => ..., 100)` after render
